DealerPilot AI — Sprint 4.8

Autonomous Publishing Engine + Photo Quality Decision

Sprint 4.7 is complete.

Before building Sales AI, we need to complete the Marketplace publishing automation layer.

DO NOT modify:

* Inventory XML parser
* Listing Intelligence logic unless needed for scheduling
* Creative Intelligence schema unless needed for photo quality status
* Existing Chrome Extension connection model
* Existing UI design system

GOAL:
DealerPilot should be able to automatically select, prepare, and publish vehicles in controlled batches through the Chrome Extension.

The operator should be able to configure:

* how many vehicles to publish
* how often to publish
* what days/times to publish
* whether to require approval before final publish
* whether the extension can auto-click final Publish in controlled mode
* whether to use original photos or generated creatives

Default Alpha rule:
Publish 3–4 vehicles every 2 days.

MODULE 1 — Auto Publish Schedule

Create a new section inside Marketplace AI:

Auto Publish Plan

Fields:

* enabled / disabled
* vehicles per batch
* frequency: daily, every 2 days, weekly
* preferred posting window
* max posts per day
* minimum delay between posts
* require operator approval before final publish: true/false
* auto-click final Publish: true/false
* use original photos if quality score is good: true/false
* generate AI creative only if photo score is low: true/false

Default:

* enabled: false
* vehicles per batch: 4
* frequency: every 2 days
* max posts per day: 4
* minimum delay: 10–20 minutes
* require operator approval: true
* auto-click final Publish: false initially
* original photos if good: true
* creative only if needed: true

MODULE 3 — Vehicle Selection Logic

DealerPilot should automatically select vehicles for publishing.

Selection rules:

* status Active or Ready
* not already Published
* has enough photos
* has price
* has mileage
* has VIN
* prioritize:
    * trucks
    * SUVs
    * high-margin vehicles
    * fresh inventory
    * vehicles with strong photo quality
    * vehicles not posted before

Avoid:

* sold/removed vehicles
* missing price
* missing VIN
* missing photos
* vehicles already live
* vehicles with failed validation

Create a publish_priority_score.

⸻

MODULE 4 — Photo Quality Analyzer

Before deciding whether to generate a creative, analyze the XML photos.

Photo Quality Score 0–100.

Evaluate:

* number of photos
* first photo quality
* vehicle visibility
* image resolution
* lighting
* background cleanliness
* angle
* duplicates
* interior/exterior variety
* blurry/dark photos

Decision:

* score 80–100: use original photos
* score 60–79: use original photos but recommend AI cover
* score below 60: generate AI Creative before publishing
* missing photos: mark Needs Review

Create fields:

* photo_quality_score
* photo_quality_label
* photo_decision
* recommended_cover_image
* needs_ai_creative

MODULE 7 — Chrome Extension Auto Publish Mode

Extend the extension to support batch publishing.

Modes:

1. Assisted Mode

* fill form
* operator manually clicks Publish

2. Controlled Auto Mode

* fill form
* validate fields
* optional screenshot/preview
* click Publish automatically only if:
    * auto-click final Publish is enabled
    * all validation checks pass
    * no Facebook checkpoint/login/captcha/security warning
    * job belongs to this extension
    * posting limit not exceeded

Safety:

* stop immediately if Facebook shows login, checkpoint, captcha, suspicious activity, restriction, or error
* do not store Facebook password
* do not bypass security
* log every step
* send step progress to backend
