====================================================
PART 4 — Meta Catalog Adapter
====================================================

Build DealerPilot-hosted Meta-ready feed.

Do not send Alpha XML directly to Meta.

Create:

GET /api/channels/meta-catalog/feed.xml
GET /api/channels/meta-catalog/feed.csv

These feeds must be generated from normalized DealerPilot inventory.

Required fields:
- id
- title
- description
- availability
- condition
- price
- link
- image_link
- additional_image_link
- make
- model
- year
- trim
- body_style
- mileage
- vin
- exterior_color
- dealer_name
- address if available

Price format:
“36900 USD”

Availability:
in stock / out of stock

Condition:
used / new

Images:
- primary image = image_link
- gallery images = additional_image_link
- preserve order
