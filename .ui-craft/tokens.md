## Direction

- Style: restrained operational dashboard
- Theme: light by default, intentional dark token mapping retained
- Accent: soft UI Craft blue; never decorative blue-violet gradients
- Density: 7/10
- Variance: 4/10
- Motion: 2/10; color, opacity, and short state transitions only
- Signature: DP monogram plus a precise soft-blue active-navigation rail

## Color

- Canvas: warm neutral, `hsl(30 20% 98%)`
- Raised surface: white, `hsl(0 0% 100%)`
- Primary text: charcoal, `hsl(220 18% 14%)`
- Secondary text: `hsl(220 8% 42%)`
- Border: `hsl(220 13% 88%)`
- Accent: soft blue, `hsl(213 62% 45%)`
- Accent soft: `hsl(213 50% 95%)`
- Success, warning, and destructive colors are semantic only

## Typography

- Body/display: `"Segoe UI Variable", "Segoe UI", system-ui, sans-serif`
- Data: `"Cascadia Code", "SFMono-Regular", Consolas, monospace`
- Page title: 30px/1.15, 600, -0.025em
- Section title: 16px/1.3, 600
- Body/control: 14px/1.5, 400–600
- Caption: 12px/1.4, 500
- All operational numbers use tabular figures

## Spacing and geometry

- Scale: 4, 8, 12, 16, 24, 32, 48px
- Page padding: 24px desktop, 16px mobile
- Card padding: 16–20px
- Table row: 44px minimum
- Input radius: 6px
- Card radius: 10px
- Modal radius: 14px
- Pill radius: full only for true statuses or compact controls

## Elevation and motion

- Raised: `0 1px 2px rgb(15 23 42 / .04), 0 4px 12px rgb(15 23 42 / .035)`
- Overlay: `0 10px 30px rgb(15 23 42 / .10), 0 2px 8px rgb(15 23 42 / .06)`
- Fast: 120ms
- Normal: 180ms
- Slow: 260ms
- Easing: `cubic-bezier(.16, 1, .3, 1)`
- No bounce, decorative glow, idle float, or entrance choreography
